# UMH Product Screenshot Tool 🦍

Internal tool for creating standardized changelog screenshots. Runs entirely in the browser — images never leave your machine.

**Use it:** https://rao1396.github.io/umh-screenshot-tool/

Standards baked in: navy #0f192e frame, 16:9, fixed top-left anchor (80px), edge fades, WebP export at 2560×1440.
